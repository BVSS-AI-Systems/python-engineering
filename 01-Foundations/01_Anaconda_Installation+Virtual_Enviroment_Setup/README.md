# 1. Anaconda Installation & Virtual Environment Setup

This folder contains the materials and resources required to set up Anaconda and create isolated Python virtual environments using Conda. It covers the installation process, environment creation, activation/deactivation, package management, and best practices for maintaining separate development environments for different projects.

By the end of this module, you will be able to install Anaconda, manage Conda environments, work with multiple Python versions, and prepare a clean workspace for Python development, Data Science, and Machine Learning projects.
