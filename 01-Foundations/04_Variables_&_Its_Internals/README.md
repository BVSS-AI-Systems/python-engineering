
# Variables & Their Internals

This folder explores one of the most important concepts in Python: variables and how they work internally. Rather than viewing variables as containers that store values, this module explains how variables act as references to objects in memory.

The content covers Python's object model, memory management, variable assignment, reference counting, mutability and immutability, object identity, and common pitfalls related to shared references and in-place modifications.

By understanding these internal mechanics, learners will gain a deeper understanding of Python's execution model and be able to write more predictable and efficient code.

## Topics Covered

- Variables and Object References
- Everything is an Object
- Object Identity and Memory Addresses
- Assignment and Multiple Assignment
- Reference Counting
- Mutable vs Immutable Objects
- List and Integer Behavior
- Variable Aliasing
- In-place Modification (`+=`) vs Reassignment (`+`)
- Function Arguments and Object References
- Stack Frames and Heap Objects
- Python Memory Internals
- Common Variable-Related Pitfalls and Interview Questions

## Learning Outcomes

After completing this module, you will be able to:

- Understand how variables reference objects.
- Explain Python's object model.
- Differentiate between mutable and immutable objects.
- Predict the behavior of assignments and object mutations.
- Analyze reference sharing and memory usage.
- Understand how function arguments are passed in Python.
- Debug common bugs caused by object aliasing and shared references.
- Visualize Python programs using stack and heap diagrams.
