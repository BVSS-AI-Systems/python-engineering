
# Control Flow in Python

## Introduction

Control flow determines the order in which statements in a program are executed. By default, Python executes statements sequentially from top to bottom. Control flow statements allow us to make decisions, repeat actions, and alter the execution path of a program.

---

## Topics Covered

### 1. Conditional Statements
Used to execute code based on conditions.

- `if`
- `if-else`
- `if-elif-else`
- Nested `if`

---

### 2. Looping Statements
Used to execute a block of code repeatedly.

#### `for` Loop
Iterates over a sequence such as a string, list, tuple, set, or dictionary.

#### `while` Loop
Executes a block of code as long as a condition remains true.

---

### 3. Loop Control Statements

#### `break`
Immediately terminates the loop.

#### `continue`
Skips the current iteration and moves to the next iteration.

#### `pass`
Acts as a placeholder and performs no action.

---

### 4. Nested Loops
A loop inside another loop.

---

### 5. Conditional Expressions
Writing simple conditions in a compact form.

---

### 6. Pattern-Based Problem Solving
Using loops and conditions together to solve logical and pattern-based problems.

---

## Learning Outcomes

After completing this section, you will be able to:

- Understand program execution flow.
- Make decisions using conditional statements.
- Repeat tasks efficiently using loops.
- Control loop execution with break, continue, and pass.
- Combine conditions and loops to solve practical programming problems.
- Build a strong foundation for functions, data structures, and algorithms.
