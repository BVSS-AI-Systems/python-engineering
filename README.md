## Beyond writing code

I want to understand what happens behind the code—how Python works, why certain approaches fit a problem, and how small decisions shape a larger system.

This repository is where I’ll explore those questions through practical tasks, personal notes, and projects. For each topic, I’ll complete multiple exercises and document my work step by step.

Along the way, I’ll share useful resources, mistakes, fixes, and discoveries. Wherever helpful, I’ll include diagrams to explain execution flow, memory behavior, or application architecture.

## What’s inside

| | What I’ll share |
| :--- | :--- |
| **📝 Notes** | Concepts explained in my own words, with examples that make them easier to revisit. |
| **💻 Practical tasks** | Multiple exercises per topic, including code, implementation steps, and results. |
| **🧩 Projects** | Small tools and applications that bring different concepts together. |
| **🔎 Discoveries** | Debugging experiences, unexpected behavior, and lessons from experimentation. |
| **📐 Visual explanations** | Diagrams for concepts and systems wherever they add clarity. |
| **🔗 Resources** | Helpful documentation, articles, videos, and references. |

## What I’ll explore

| Focus | Topics |
| :--- | :--- |
| **Foundations** | Computational thinking, variables, memory, functions, data structures, files, and testing |
| **Language depth** | OOP, iterators, generators, concurrency, packaging, and distribution |
| **Advanced Python** | Descriptors, metaclasses, typing, asynchronous patterns, and security |
| **Python for AI & ML** | NumPy, pandas, scientific computing, PyTorch, JAX, LLM APIs, and vector search |
| **Application architecture** | Design patterns, SOLID, domain modeling, FastAPI, gRPC, and event-driven systems |
| **Production engineering** | Profiling, optimization, logging, metrics, tracing, and distributed workloads |
| **Systems & internals** | CPython, the GIL, garbage collection, bytecode, networking, IPC, and C extensions |

> **A growing collection.** I’ll add notes, tasks, projects, and resources as I explore each topic and put it into practice.
